# UI/UX Roadmap

Phase 1 is the first polish pass: clearer sidebar grouping, calmer view controls, stronger media row hierarchy, more compact player navigation, and a more legible media details panel.

## Phase 2: Interaction Upgrades

- Add keyboard shortcuts for play/pause, previous, next, search focus, favorite, watch later, edit details, and dialog close.
- Improve dialog focus handling so modals trap focus, restore focus on close, and respond consistently to Escape.
- Add richer scan feedback with last scan time, files added, files removed, missing file count, and thumbnail generation status.
- Make loading, disabled, and empty states more specific for locked categories, filtered views, failed thumbnails, and missing `VIDEO_ROOT`.
- Add clearer route-aware browser titles so category and media pages are easier to identify when bookmarked or shared locally.

## Phase 3: Library Power Tools

- Add bulk selection for media rows.
- Support bulk move, bulk category/subcategory edits, bulk tag edits, bulk favorite/watch-later changes, and bulk delete confirmation.
- Add a tag browser so tags are navigable, not only searchable.
- Add a trash and restore flow before permanent deletion.
- Add richer category management for subcategories, including clearer constraints around the current two-level folder structure.
- Add optional compact/dense browsing modes for large libraries.
